# Canaã Soluções Agrícolas

Site institucional e vitrine de soluções agrícolas para produtores de São Roque do Canaã, Espírito Santo.

## Conteúdo

- Hero com chamada para atendimento e compras pelo WhatsApp.
- Categorias de fertilizantes, adubos e defensivos.
- Informações sobre a agricultura local.
- Endereço, mapa e canais de contato da unidade.
- Layout responsivo para desktop e dispositivos móveis.

## Tecnologias

- HTML5 semântico
- CSS3 modular
- Flexbox e CSS Grid
- Menu mobile feito com CSS
- Google Fonts

## Estrutura

```text
.
├── css/
```

## Execução

Por ser um projeto estático, abra o arquivo `index.html` diretamente no navegador ou use uma extensão de servidor local no VS Code.
